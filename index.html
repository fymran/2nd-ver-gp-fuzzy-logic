Mathematical Framework

1️⃣ Level 1: Fuzzification

Triangular Membership Functions (trimf)

AC Temperature (16-28°C):

• Inefficient: [15,16,20]

• Balanced: [18,21,24]

• Efficient: [22,28,29]

Plug Load (0-3000W):

• Low: [-100,0,500]

• Active: [400,1100,1800]

• Heavy: [1500,3000,3100]

2️⃣ Level 1: Mamdani Inference

Rule-based fuzzy logic engine

Rule Aggregation:

μ_output = max(min(μ_A, μ_B), min(μ_C, μ_D))

Sample Rules:

  • IF (AC Ineff) AND (Plug Heavy) → POOR
  • IF (AC Eff) AND (Plug Low) → EXCELLENT
  • IF (Fan Mod) AND (Plug Act) → AVERAGE

3️⃣ Level 1 Output: Defuzzification

Centroid Method (Center of Gravity):

z* = ∫ μ_C(z) · z dz / ∫ μ_C(z) dz

where μ_C is the aggregated membership function and z is the output variable range [0-100]

4️⃣ Level 2: Hierarchical Aggregation

Process:

  1. Calculate L1 efficiency for each room
  2. Aggregate all room scores arithmetically
  3. Compute global average
  4. Determine system status

Status Mapping:

🟢 Optimal: > 75%

🟡 Moderate: 45-75%

🔴 High Waste: < 45%

Implementation Notes

  • ✓ Trimf Function: max(0, min((x-a)/(b-a), (c-x)/(c-b)))
  • ✓ Defuzzification Sampling: 0-100% range in 10-unit steps
  • ✓ Real-time Updates: Synchronized across all views
  • ✓ Multi-room Scaling: Independent Level 1 systems aggregated at Level 2
