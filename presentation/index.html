Fuzzy Expert System Model

Understanding the Core Components

Knowledge Base

Contains 9 fuzzy rules for room efficiency and 5 fuzzy sets for global efficiency. Represents domain expertise in energy optimization.

Knowledge Acquisition

Documents how knowledge was gathered through parameter selection based on real-life device constraints and energy consumption patterns.

Fuzzification

Converts crisp input values (AC temp, fan speed, plug load, lamp intensity) into fuzzy membership values using triangular membership functions.

Inference Engine

Applies the Mamdani MIN operator to evaluate fuzzy rules and generate fuzzy outputs based on the current input state.

Aggregation

Combines outputs from multiple fuzzy rules using the MAX operator to create a unified fuzzy output set for each category.

Defuzzification

Converts aggregated fuzzy outputs into crisp efficiency scores (0-100%) using the Centroid (Center of Gravity) method.

Knowledge Acquisition

Decision-Making Process & Parameter Selection

AC Temperature (16-28°C)

Source: Real-life device constraints

Typical air conditioner remote controllers have temperature ranges between 16°C and 28°C. Below 16°C is unsafe/unusable, above 28°C provides minimal cooling.

Inefficient: 15-20°C Balanced: 18-24°C Efficient: 22-29°C

Fan Speed (0-5)

Source: Real-life device constraints

Standard exhaust fans and HVAC systems typically have 5-level speed controls. Level 0 = off, Level 5 = maximum ventilation capacity.

Low: 0-1.5 Moderate: 1-3.5 High: 3-6

Plug Load (0-3000W)

Source: Typical household appliances

Research-based estimation of household appliance consumption: Microwave (~1000W), Heater (~2000W), Multiple appliances (~3000W max safe load).

Low: 0-500W Active: 400-1800W Heavy: 1500-3100W

Lamp Intensity (0-100%)

Source: Smart lighting systems

Modern smart lights and dimmers allow continuous intensity control. Assumption: intensity can be controlled from 0-100%, though traditional lights are on/off.

Dim: 0-35% Standard: 30-75% Bright: 65-105%

Fuzzy Rule Design Process

9 rules designed across 3 categories to capture dominant energy patterns:

Category Rule Count Logic Pattern Example Rule
Poor Efficiency 3 rules High consumption + Wasteful cooling IF (AC Inefficient) AND (Plug Heavy) AND (Lamp Bright) THEN Poor
Excellent Efficiency 3 rules Low consumption + Efficient cooling IF (AC Efficient) AND (Plug Low) AND (Lamp Dim) THEN Excellent
Average Efficiency 3 rules Balanced/Mixed conditions IF (Fan Moderate) AND (Plug Active) AND (Lamp Standard) THEN Average

Implementation

Detailed Process Flow

1. Fuzzification

Goal: Convert crisp inputs to fuzzy values using triangular membership functions (trimf).

trimf(x, a, b, c) = max(0, min((x-a)/(b-a), (c-x)/(c-b)))

Input Variables:

  • AC Temperature (16-28°C) → 3 fuzzy sets
  • Fan Speed (0-5) → 3 fuzzy sets
  • Plug Load (0-3000W) → 3 fuzzy sets
  • Lamp Intensity (0-100%) → 3 fuzzy sets

2. Rule Evaluation

Goal: Apply Mamdani MIN operator to evaluate fuzzy rules.

Rule output = min(μ_input1, μ_input2, μ_input3)

Example Rule Evaluation:

IF (AC=ineff:0.7) AND (Plug=heavy:0.8) AND (Lamp=bright:0.9)
THEN Poor = min(0.7, 0.8, 0.9) = 0.7

3. Aggregation

Goal: Combine outputs from multiple rules using MAX operator.

μ_category = max(rule1_output, rule2_output, rule3_output)

Example Aggregation:

Poor_strength = max(0.7, 0.6, 0.8) = 0.8
Average_strength = max(0.4, 0.5) = 0.5
Excellent_strength = max(0.2, 0.3) = 0.3

4. Defuzzification

Goal: Convert fuzzy outputs to crisp efficiency score using Centroid method.

Score = Σ(i × μ(i)) / Σ(μ(i))

Process: Integrate over output range [0-100%] using 10% steps to find center of gravity.

  • Scenario A (Minimum): Demonstrates maximum efficiency potential with all systems at minimal load. All rooms achieve high efficiency scores (90%+).
  • Scenario B (Maximum): Shows system response under maximum stress. All rooms experience low efficiency scores (15-25%), indicating high energy waste.

  • System Consistency: The fuzzy logic system demonstrates consistent rule application across all scenarios and rooms.

Conclusion

Summary of Findings

The Hierarchical Fuzzy Inference System (HFIS) demonstrates an effective approach to multi-room energy efficiency analysis. By combining fuzzy logic principles with hierarchical aggregation, the system provides nuanced efficiency assessments based on multiple interrelated appliance parameters.

System Effectiveness

✓ Rule Completeness

9 rules strategically cover 3 primary efficiency categories, balancing comprehensiveness with interpretability. While representing only ~11% of theoretical combinations, the rules capture dominant energy patterns.

✓ Input Handling

Triangular membership functions successfully represent real-world constraints from AC remote controllers (16-28°C), fan speed controls (0-5), and household appliance consumption (0-3000W).

✓ Inference Quality

Mamdani MIN operator correctly identifies rule triggering conditions, while Centroid defuzzification produces smooth, continuous efficiency scores responsive to input changes.

✓ Hierarchical Integration

Two-level architecture effectively isolates room-level complexity while providing global house-level insights through simple arithmetic averaging.

Practical Applications

  • Smart Home Management: Real-time monitoring of multi-room energy efficiency for homeowners
  • Energy Optimization: Identification of efficiency bottlenecks and consumption patterns
  • Automated Control: Foundation for automated systems to reduce energy waste
  • User Feedback: Intuitive efficiency metrics (0-100% scores) for user education

Future Enhancements

  • Expansion of fuzzy rule set for finer granularity
  • Implementation of Level 2 fuzzy inference (currently arithmetic average)
  • Machine learning optimization of membership function parameters
  • Temporal analysis tracking efficiency trends over time
  • Integration with smart home devices for automated control
